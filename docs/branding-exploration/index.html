About the extremely serious name

Why
railgun?

git-railgun because gitrail was taken, and railguns > just rails.

It’s a tiny, read-only Git sidebar with an unnecessarily high-velocity name. The product keeps repository state exact and boring. The identity is allowed to be neither.

Yes, there is actual software under here

Silly name.
Sensible rail.

GitRail sits beside a Herdr or cmux pane and shows the exact state you’re about to inspect. It does not write, stage, reset, rebase, rewrite history, or accidentally vaporize the worktree.

Three big ideas

Same angle.
Different abstraction.

The first-person vertical read is non-negotiable. The useful question is how literally the files become the weapon.

01 / literal translation

Loaded Spine

Files are physical ammunition plates inside the hot orange housing. Closest to the Quake II view and clearest at first glance.

Best for: homepage hero, launch art, splash screen
02 / graphic translation

Arena Print

Hard screen-print shapes make the weapon feel like a brand asset instead of game concept art. Strongest color and silhouette system.

Best for: docs covers, release posters, social
03 / typographic translation

Repository Totem

The files don’t sit on the gun—they are the gun. A single selected path continues upward as the beam.

Best for: motion, terminal animation, campaign identity
01
Wide at the player

The housing should feel massive at the bottom edge, not like a neat logo floating in space.

02
Files recede upward

Rows get narrower and tighter as they approach the muzzle. Perspective supplies the velocity.

03
Orange shell, black spine

The color blocking does most of the Quake II recognition before any detail is visible.

04
One path fires

The active file changes from bone to white-hot; its name can stretch into the beam or target.

05
Git is the HUD

Green additions, red deletions, and status counts belong inside the gun instead of around it.
